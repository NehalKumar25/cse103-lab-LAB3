## Overview

This repository contains lab work for **LAB 3** of the Computer Fundamentals & Career Pathways (CSE103) course at **K.R. Mangalam University**, Gurugram.

The main objective is to understand Git, GitHub collaboration, Markdown documentation, and API interaction.

## How to Run

Clone the repository:

```bash
git clone https://github.com/NehalKumar25/cse103-lab-LAB3.git
```

Navigate to the project:

```bash
cd cse103-lab-LAB3
```

Run the Python program:

```bash
python main.py
```
